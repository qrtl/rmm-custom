This module allows adjusting the visibility of the “Add Custom Filter”
and “Add Custom Group” options in the search view by introducing a new
group: “Custom Filter and Group By Access”. Only users who belong to
this group can see these options.

By default, internal users are included in this group.

Configuration
=============

To show “Add Custom Filter and "Add Custom Group" for specific users:

-  Go to Settings → Users & Companies → Groups.
-  Search for "Custom Filter and Group By Access".
-  Open the group and add the desired users.

To show “Add Custom Filter and "Add Custom Group" for all users in a
specific group:

-  Go to Settings → Users & Companies → Groups.
-  Search and open the group you want to grant access to.
-  Under the Inherited tab, add "Custom Filter and Group By Access"
   group.
