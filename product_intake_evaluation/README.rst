Products can be registered in Odoo by portal users and then evaluated
and managed.

This is intended for operations such as second-hand businesses, where
products are registered in advance by portal users, and only accepted
products are brought into the second-hand warehouse.

Internal users can review the product information registered by portal
users (images, condition, comments, etc.) and update the valuation
status. Portal users can check that status and confirm whether their
product has been marked as acceptable. Only acceptable products are
actually delivered.

The user access rights for the Intake Evaluation feature are as follows:

1. Intake Evaluation Admin: Assigned to internal users who manage the
   Intake Evaluation functionality.
2. Intake Evaluation Manager: Portal user role that allows viewing of
   all products registered by all portal users.
3. Intake Evaluation User: Portal user role that allows viewing only of
   products registered by themselves.

This module depends on the OCA base_group_backend module.

Usage
=====

Portal User Settings
--------------------

-  Go to Settings > Users & Companies > Users and click Create.
-  Set User Type to Backend UI user
-  Enable either Intake Evaluation User or Intake Evaluation Manager.

Intake Evaluation Form View
---------------------------

-  When Intake Evaluation Users and Intake Evaluation Managers log in,
   they can only see the Intake Evaluation application.

-  Both roles are able to create products.

-  When a product is created:

   -  The Sales Office field is automatically filled with the name of
      the user who created it.
   -  If the product is created by an internal user, Sales Office is not
      recorded.

-  Access rules:

   -  Intake Evaluation Users can only view products where the Sales
      Office matches their own record.
   -  Intake Evaluation Managers can view products assigned to any sales
      office.

-  The value entered in the Sales Office field must be a contact with
   the Intake Evaluation Partner field enabled.

-  This is automatically enabled when a user is created as an Intake
   Evaluation user or manager.

Intake Evaluation List View
---------------------------

-  Intake Evaluation Users can export data using the Export button
   located next to the Create button at the top left.
-  Records can also be grouped or searched by status or product name
   using the search view.

Internal User View
------------------

-  In Inventory > Products, a new Evaluation Information tab has been
   added.
-  Edits made here are reflected in the Intake Evaluation module.
-  Internal users typically update statuses from this tab.

Branch and Sales Office
-----------------------

-  In the partner form view, a new Intake Evaluation Information tab has
   been added.
-  This tab includes the Branch field.

When an Branch is selected in the sales office, the product’s Branch
field is automatically populated.
