To use this module, configure the OpenAI API key under the Company
settings in Odoo.

The official Python SDK from OpenAI is required. Install it using:

``` bash
pip install openai
```
Configuration in Odoo

- Set your OpenAI API key in Company Settings in Odoo.
- Settings > Technical Settings > OpenAI Vision Sessions. Adjust parameters such as model, temperature, instructions, and response schema as needed.

For additional options and usage details, refer to the official
documentation: <https://platform.openai.com/docs>
