This module defines openai.vision.session to call OpenAI’s GPT-4o with structured
payloads. It supports image/text inputs, web search, and optional JSON schema output.
Designed to be used by other modules, not standalone. Use call_openAI() to trigger
requests. Enable store_response to keep previous_response_id for chaining.

Using a job queue (e.g., queue.job) is recommended for asynchronous execution.

=============

Set your company’s openai_api_key in Odoo
Install the OpenAI Python SDK: pip install openai
